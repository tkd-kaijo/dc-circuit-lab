# 直流回路ラボ

抵抗を含む RC・RL・RLC 回路について、スイッチ操作後の過渡現象を観察する教材用シミュレーターです。

## 起動

`index.html` をブラウザで直接開きます。外部ライブラリやビルドは不要です。

## iPadのホーム画面に追加

Safariで公開ページを開き、共有ボタンから「ホーム画面に追加」を選ぶと、専用アイコンと「直流回路」という名前で追加されます。起動後はブラウザの操作部分を表示しないアプリ風の画面になります。

## 回路

- RC直列：直流電源による充電、抵抗を通した放電
- RL直列：直流電源接続後の電流の立ち上がり、電源切り離し後の減衰
- RLC直列：直流電源を入れた後の過渡応答、コンデンサー充電後に電源を外した後の自由応答

## 表示規則

- 赤い粒：慣用電流。色・濃さ・大きさは変えず、粒の移動方向と速さだけで、その時刻の電流の向きと大きさを表します。
- 青い二等辺三角形：素子両端の瞬時電圧。30°の頂点側が低電位で、電位差が大きいほど三角形が大きくなります。
- 電圧の三角形は再生前には表示せず、「再生」で時間が進み始めてから表示します。
- 波形：上段に電圧、下段に電流を表示します。再生中は現在時刻までを順に描き、縦のカーソルは回路図と同じ時刻です。
- グラフの時間軸と縦軸は回路ごとの初期設定を基準に固定し、R・L・Cを変更しても自動スケールしません。
- 初期表示、回路・設定値の変更、「初めに戻す」の後は停止し、「再生」を押すまで始まりません。
- 充電・電流の立ち上がり・電源を入れるモードでは、「再生」の後に約1秒かけてスイッチが閉じ、閉じ切った瞬間を `t = 0` として回路とグラフが動き始めます。
- すべての回路に抵抗 R を含め、理想電源・理想コイル・理想コンデンサーとして計算します。
